📚 Membangun Definisi Formal

Tahap 1: Pengertian Sederhana

Invers Fungsi adalah fungsi yang "membalikkan" kerja fungsi asli.

Jika fungsi f mengubah A menjadi B, maka invers f⁻¹ mengubah B kembali menjadi A.

Tahap 2: Notasi dan Simbol

Fungsi Asli

y = f(x)

Dibaca: "y sama dengan f dari x"

Fungsi Invers

x = f⁻¹(y)

Dibaca: "x sama dengan f invers dari y"

Tahap 3: Definisi Matematis

Definisi Formal:

Fungsi f⁻¹ adalah invers dari fungsi f jika dan hanya jika:

f(f⁻¹(x)) = x

untuk setiap x dalam domain f⁻¹

f⁻¹(f(x)) = x

untuk setiap x dalam domain f

⚖️ Syarat-syarat Invers Fungsi

Syarat 1: Fungsi Harus Satu-satu (Injektif)

✅ Contoh BENAR

f(x) = 2x + 3

f(1) = 5

f(2) = 7

f(3) = 9

Setiap input menghasilkan output berbeda

❌ Contoh SALAH

g(x) = x²

g(-2) = 4

g(2) = 4

g(-3) = 9

g(3) = 9

Input berbeda menghasilkan output sama

Syarat 2: Fungsi Harus Onto (Surjektif)

Setiap elemen di kodomain harus menjadi hasil pemetaan dari domain.

Domain f

Semua bilangan real

Kodomain f

Semua bilangan real

📋 Kesimpulan Syarat

Fungsi memiliki invers jika dan hanya jika fungsi tersebut BIJEKTIF

Bijektif = Injektif (satu-satu) + Surjektif (onto)

Uji Garis Horizontal:

Jika setiap garis horizontal memotong grafik fungsi tepat di satu titik, maka fungsi memiliki invers.

🔬 Analisis Mendalam dengan Contoh

Contoh 1: Fungsi Linear f(x) = 3x - 2

Langkah 1: Cek Syarat

✅ Satu-satu: Gradien ≠ 0

✅ Onto: Domain = Kodomain = ℝ

Memiliki invers!

Langkah 2: Cari Invers

y = 3x - 2

x = 3y - 2

x + 2 = 3y

y = (x + 2)/3

Langkah 3: Verifikasi

f(f⁻¹(x)) = f((x+2)/3)

= 3((x+2)/3) - 2

= x + 2 - 2 = x ✅

Contoh 2: Fungsi Kuadrat g(x) = x²

Analisis Syarat

❌ Tidak satu-satu: g(-2) = g(2) = 4

❌ Tidak onto: tidak ada x yang menghasilkan y < 0

Tidak memiliki invers!

Solusi: Pembatasan Domain

Batasi domain: x ≥ 0

Maka g(x) = x², x ≥ 0

Inversnya: g⁻¹(x) = √x, x ≥ 0

Sekarang memiliki invers!

🔍 Cara Mencari Fungsi Invers

📋 Langkah-langkah:

1

Tulis y = f(x)

2

Tukar posisi x dan y

3

Selesaikan untuk y

4

Tulis y = f⁻¹(x)

💡 Contoh: f(x) = 2x + 3

1. y = 2x + 3

2. x = 2y + 3

3. x - 3 = 2y

y = (x - 3)/2

4. f⁻¹(x) = (x - 3)/2
